# Threadline

**A living builder workspace — one place to capture ideas, track active projects, remember blockers, connect learnings across repos, surface reusable patterns, and help move things from idea → validation → build → live.**

The "thread" is the continuity across all of it: ideas, context, GitHub activity, ChatGPT/Copilot learnings, and next actions.

---

## Why this exists

Most builders juggle multiple projects. Ideas evaporate. Context gets trapped in silos. Dashboards go stale. You forget what you were excited about last week.

Threadline solves this by being the **single starting point** — not an afterthought dashboard, but the place where every project begins, lives, and stays connected.

## Core principles

- **Never lose an idea** — frictionless capture, phone-friendly
- **Always current** — auto-syncs with GitHub activity, no manual updates
- **Lifecycle-aware** — idea → validated → building → live → archived
- **Cross-project memory** — shared patterns, learnings, reusable components
- **Gentle nudges** — surfaces stalled work and pending blockers
- **Multiple views** — slice and dice by stage, category, energy, recency

## Tech stack

- GitHub Pages (always accessible, any device)
- PWA (installable on phone home screen)
- GitHub API (auto-pull repo activity)
- JSON data layer (portable, version-controlled)
- Designed for open-source contribution later
